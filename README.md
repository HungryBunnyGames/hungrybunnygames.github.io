# hungrybunnygames.com

The public site for **Hungry Bunny Games**.

This repository contains the website only.

## How it works

- `index.html` — the entire site. Plain HTML and CSS, no build step, no dependencies.
- `CNAME` — tells GitHub Pages this repo answers to `hungrybunnygames.com`. Do not delete.
- `.nojekyll` — tells GitHub Pages to serve the files as-is.

## To change the site

Edit `index.html`, commit, push. GitHub rebuilds within about a minute.
